Banco de Dados PostgreSQL

Programação de Formação HI Tecnologia

Um banco de dados é um sistema digital seguro para organizar, salvar e acessar grandes volumes de informações sem erros, sendo o PostgreSQL uma das opções gratuitas e robustas mais utilizadas por aplicativos e empresas. Nesta etapa, você terá contato com o pgAdmin, a plataforma de administração e desenvolvimento visual do Postgres, e aprenderá a utilizar comandos básicos de SQL, como INSERT e SELECT, para manipular e consultar seus dados. Para garantir a organização do seu aprendizado, não se esqueça de salvar os arquivos das aulas em pastas individuais para cada tema, dentro do seu diretório localizado em: L:\GAdmn\DSuporte Tecnico\Minha Pasta.
